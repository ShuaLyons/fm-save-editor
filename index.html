      Edit your Yu-Gi-Oh! Forbidden Memories save

      This free save editor for Yu-Gi-Oh! Forbidden Memories on the PlayStation (PS1) lets you change your deck, the cards in your trunk and your starchips, right in your browser. It works with the US, European and Japanese (Shin Duel Monsters) versions of the game.

      • Put any of the game's 722 cards into any of your 40 deck slots.
      • Set how many copies of each card you own, or get 1 or 3 of every card at once.
      • Set your starchips, or max them out with one click.
      • See ATK/DEF, type, level, password and starchip cost for every card.
      • Import and export decks as text.

      How to use it

      1. Close your emulator so it isn't using the memory card file.
      2. Click Choose file and pick your memory card file.
      3. Edit your deck, trunk and starchips, then click Save changes.
      4. Replace your old memory card file with the downloaded one, keeping a backup of the old one.
      5. Start the game and use its Load option, not an emulator save state.

      Questions

      Which emulators and memory card files work?

      DuckStation (.mcd), ePSXe and Mednafen (.mcr), RetroArch (.srm) and DexDrive (.gme). Most raw 128 KB PS1 memory card images work.

      Is my save uploaded anywhere?

      No. Everything happens in your browser and your file never leaves your computer. You can also download the page and use it offline.

      Will the game accept the edited save?

      Yes. Forbidden Memories checks its save data with a checksum. The editor recalculates it exactly as the game does, so edited saves load normally.

      Which versions of the game are supported?

      US (SLUS-01411), European (SLES-03947 to SLES-03951) and Japanese Yu-Gi-Oh! Shin Duel Monsters (SLPM-86396, SLPM-86398 and SLPM-86573).
